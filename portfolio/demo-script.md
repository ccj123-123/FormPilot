# FormPilot 60–90 秒作品集演示脚本

## 当前可录制版

目标时长：约 90 秒。录屏只展示当前能够复现的输入、校验、生成与导出流程；实物适配结果和 V2 不提前宣称。

| 时间 | 画面 | 旁白 | 操作 | 证据 |
| --- | --- | --- | --- | --- |
| 0–10 秒 | 桌面上并排放置手机与耳机盒，切到 FormPilot 首页；标题叠字：“一个底座，尺寸必须真实可制造。” | “我想为手机和耳机盒做一个桌面底座，但自然语言里的‘放得下’并不是可制造尺寸。” | 展示需求输入框，输入简短用途描述。 | 原始需求文字完整留在画面中，不展示尚未发生的生成结果。 |
| 10–25 秒 | 界面提示缺失的关键尺寸，随后展示手工参数区。 | “当描述缺少尺寸时，FormPilot 不会猜测设备大小，而是要求补充测量值；也可以直接走手工参数流程。” | 按界面字段填入手机宽厚、耳机盒宽厚、间隙和布局；使用 `portfolio/v1-parameters.json` 的演示值时，在画面注明“通用演示参数，非本人设备实测”。 | 缺失尺寸提示、已填写字段，以及参数来源说明同屏可见。 |
| 25–45 秒 | 生成完成后，界面显示真实 3D 预览与状态摘要。缓慢旋转模型，特写手机槽、耳机槽与底座边缘。 | “输入在后台形成结构化设计规格，并经过确定性尺寸与网格检查；当前界面只展示生成状态摘要和可交互的 3D 结果。” | 点击生成；读取界面实际显示的成功或失败摘要；旋转、缩放 3D 模型。若生成失败，保留真实错误摘要并说明需要修改参数后重试。 | `Model3D` 预览与界面状态摘要；不声称隐藏的 `gr.State`、结构化校验报告或网格报告可在 UI 中展开，也不以预览代替实物适配证据。 |
| 45–60 秒 | 下载区显示 STL 与设计 JSON；下载后用文本编辑器打开 `design.json`，核对关键输入参数。若已具备切片软件，可选插入真实 STL 导入画面；否则叠字“切片画面待送印前补录”。 | “生成结果提供 STL 和设计 JSON。JSON 记录本次参数，便于下载后核对与复现；STL 可在具备切片环境时进入送印准备。” | 分别下载 STL 和 JSON；打开本次下载的 `design.json`，对照手机、耳机盒、间隙和布局参数。切片软件画面仅在实际安装并完成导入后录制。 | 可打开的 STL、本次生成的 `design.json` 及其参数；没有切片环境时，不把切片导入、耗材预估或送印准备描述为已经完成。 |
| 60–80 秒 | 全屏状态卡：“实物段待送印后补拍”。旁边列出未来必须采集的镜头：打印过程、成品、手机与耳机盒试装、间隙测量。 | “实物段待送印后补拍。目前只有数字模型和自动化检查，没有实物照片、适配反馈或 V2。收到打印件后，我会按真实试装结果补录；只有反馈确实要求修改时，才生成并展示 V2。” | 不插入示意成品照，不模拟反馈，不展示虚构的 V2；可短暂展示送印前检查清单。 | 状态卡本身明确证据边界：尚无 physical result、尚无真实 feedback、尚无 V2。 |
| 80–90 秒 | 架构图依次高亮：自然语言/手工输入 → `DesignSpec` → 校验 → OpenSCAD → 网格检查 → 下载；实物反馈节点使用醒目的 `PENDING` 标记。 | “FormPilot 的边界很清楚：AI 帮助整理意图，确定性规则生成并检查几何。它不是图像转 3D，也不替代测量、切片和真实试装；闭环要等实物验证后才成立。” | 沿数据流逐段高亮，最后停在标有 `PENDING` 的实物反馈节点。 | 架构与限制同屏；尚未完成的实物闭环由 `PENDING` 节点明确标记。 |

## 录制前准备

- 使用一个能够稳定复现的参数集；若采用仓库中的参考参数，始终标为通用演示值。
- 清空下载目录中的旧文件，确保镜头里的 STL 与 JSON 来自本次操作。
- 预先确认 3D 预览与下载链接可正常工作；只有实际具备切片软件并完成 STL 导入时才录制切片画面，否则明确标为送印前补录。
- 对任何失败状态如实录制或重新调整参数，不剪辑成从未发生过的成功结果。

## 到货后替换说明

仅替换 60–80 秒的状态卡段，其余数字流程可以保留：

1. 拍摄收到的打印件、打印方向和可辨认的表面细节。
2. 连续拍摄手机与耳机盒试装，展示是否能放入、是否晃动、取放是否顺畅。
3. 记录真实测量值与反馈，例如目标间隙和实测偏差；将原始记录作为画面证据。
4. 如果 V1 满足要求，明确说明无需 V2；如果不满足，展示真实反馈如何映射为参数修改，再生成 V2。
5. 只有在 V2 实际生成并完成相应检查后，才加入 V1/V2 对比；未再次打印时，仍要明确 V2 只有数字证据。

替换后的旁白应以实际结果为准，不预写“适配成功”或“V2 已改进”等结论。
